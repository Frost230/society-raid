# Discord GIF Bot

Este bot do Discord envia GIFs específicos para um canal ou para mensagens privadas.

## Configuração

1. Obtenha um token de bot do Discord em https://discord.com/developers/applications
2. Substitua `"your_discord_bot_token_here"` no arquivo `main.py` pelo seu token.

## Instalação

Instale as dependências:

```
pip install -r requirements.txt
```

## Como usar

Execute o bot:

```
python main.py
```

### Comandos

- `!sendgifs <channel_id>`: Envia os GIFs para o canal especificado.
- `!dmgif`: Envia os GIFs para a DM do usuário que executou o comando.
